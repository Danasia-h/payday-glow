PaydayGlow 薪动 / 上班鼓励器 · Windows 便携版 1.2.0

一、开始使用
1. 将 ZIP 压缩包完整解压到一个本地文件夹。
2. 双击 PaydayGlow.exe。无需安装、无需管理员权限，也不需要另装 .NET、Python 或 Node.js。
3. 首次打开会显示工资设置：填入你自己的月薪和上下班时间，选择工作日，保存即可。
4. 之后双击同一个 EXE，会读取这台电脑上你的设置。

二、卡片操作
- 卡片默认在主屏幕右下角，半透明、置顶，可拖动。
- 点击右上角齿轮修改设置。
- 卡片右键或任务栏右下角托盘可显示、隐藏、归位和退出。
- 右下角托盘图标可能在 Windows 的“显示隐藏的图标”箭头里。
- 隐藏卡片仍继续计时；退出后不再提醒。重复双击不会打开多个实例。

三、收入与提醒
- 月均工作日固定 21.5 天。
- 每日收入 = 月薪 / 21.5；每秒收入 = 每日收入 / 每日计薪秒数。
- 午休不计薪时，金额与进度暂停，倒计时继续。
- 下班时弹窗祝贺今天的收入，约 14 秒后自动关闭。
- 超过下班点且屏幕仍亮时，显示“被白嫖中”和超时计时；金额不继续增加。
- 锁屏不等于熄屏；系统显示器电源状态只用作提示，不代表实际在工作。
- 支持跨夜班次；不处理法定节假日、调休、请假、税费、奖金或加班费。

四、本机数据
工资、作息和提醒记录保存在：
%LOCALAPPDATA%\PaydayGlow\settings.json

不上传服务器，不含分享者的个人设置。把这个 EXE 发给别人，不会把你的工资一起发过去。
删除 EXE 不会清除设置；重置时先退出，再删除上述 PaydayGlow 数据文件夹。
运行时会在当前用户临时目录中自动展开自带的运行库，首次启动可能需要几秒。

五、系统范围
- 目标：Windows 10/11，64 位 Intel/AMD 电脑（x64）。
- Windows 7/8、32 位 Windows、macOS 不适用本 EXE。
- Windows ARM 设备未实测；此包不是原生 ARM64 构建。
- 未配置开机自启；程序运行时才会计时和提醒。
- 本版未做商业代码签名。Windows 或安全软件可能询问是否信任新应用；请由接收者按自己的安全设置判断，勿关闭系统防护。
