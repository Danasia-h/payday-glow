# 薪动 · 你的赚钱时钟

适用于 Apple Silicon Mac（M 系列芯片）。原生 SwiftUI / AppKit 应用，无需安装 Node.js、Python 或其他运行环境。构建目标为 macOS 13 及以上，已在当前 Mac 上运行验证。

## 开始使用

1. 解压「薪动-Mac.zip」，双击「薪动.app」。可以把应用拖入「应用程序」文件夹后使用。
2. 点击右下角卡片上的齿轮，或在菜单栏/卡片右键菜单中选择「工资设置」，输入月薪、上下班时间，选择每周工作日。
3. 如需扣除午休，设置午休开始和结束时间；不扣除时关闭开关。
4. 点击「保存并开始」。设置仅保存在当前 Mac 的应用偏好设置中，不上传服务器。

默认展示月薪 ¥12,000、09:00–18:00、12:00–13:00 不计薪午休、周一至周五。首次未保存时会自动打开设置窗口，且不会自动触发下班弹窗。

## 计算口径

- **月均工作日固定为 21.5 天**，按本次需求确定，不随月份、年份或每周工作日选择而变化。
- 每日预计收入 = 月薪 ÷ 21.5。
- 每秒收入 = 月薪 ÷ 21.5 ÷ 每日计薪秒数。
- 今日已赚 = 当天已过去的计薪秒数 × 每秒收入。午休不计薪时，午休期间金额暂停增长。
- 下班后今日已赚封顶为每日预计收入，不将下班后的时间算成额外收入。
- 每周工作日选择仅决定哪些日子计薪和提醒；并不改变 21.5 这个分母。

例如月薪 ¥12,000、每天计薪 8 小时：每日约 ¥558.14，每秒约 ¥0.01938。收入按时间估算，不代表实际工资结算；不处理法定节假日、调休、请假、税费、奖金及加班费。

## 下班提醒与亮屏状态

到达下班点时，弹出「下班快乐！恭喜，今天赚了 ¥…」。弹窗约 14 秒后自动消失，也可以点「收工！」关闭。每个班次只自动提醒一次，记录保存在本机，重启不会反复提醒。设置页和菜单栏提供「预览下班弹窗」，手动预览不影响当天自动提醒。

下班后，只要系统报告有在线显示器仍未休眠，卡片状态和菜单栏就显示「被白嫖中」，底部改为超时计时。使用系统屏幕休眠/唤醒事件更新状态，不需要录屏权限，不读取屏幕内容。锁屏不等于熄屏；亮屏也不代表真的在工作。

如果下班时屏幕已经休眠，不会唤醒屏幕。应用在运行的情况下，之后唤醒时会补弹当日未提醒过的下班提示。

卡片默认悬浮在屏幕右下角，距可用桌面边缘 24 点，可直接拖动。界面按参考图采用深色半透明背景、薄荷绿进度环、上班状态、四位小数的实时收入及下班倒计时。进度环按当天已过去的计薪时间计算，午休期间收入与进度暂停，倒计时继续。

菜单栏可以隐藏/显示卡片或「归位右下角」；隐藏后仍继续计时提醒。卡片右键菜单也提供工资设置和退出。应用不占用 Dock 图标。按 ⌘Q（设置窗口激活时）或选择菜单中的「退出薪动」才会彻底退出。**退出应用后不再监测和提醒；未配置开机自动启动。**

支持跨夜班次：下班时间早于上班时间时，视为次日下班。跨夜班次按上班当天的工作日安排计薪，并持续显示该班次至下个上班时间。

## 从源码构建

在已安装 Xcode 或 Apple Command Line Tools 的 Apple Silicon Mac 上，终端进入「薪动源码」目录：

```sh
zsh test.sh
zsh build.sh
open build/薪动.app
```

默认应用标识为 `local.xindong.salaryclock`。没有网络请求、外部依赖、遥测或账号系统。

屏幕事件实现依据 Apple 官方 [screensDidSleepNotification](https://developer.apple.com/documentation/appkit/nsworkspace/screensdidsleepnotification) 和 [screensDidWakeNotification](https://developer.apple.com/documentation/appkit/nsworkspace/screensdidwakenotification) 文档，初始状态使用本机 SDK 的 CoreGraphics 显示器状态 API。
